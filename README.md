# 🎓 Math & CS Hub

**بوابة كلية العلوم الرياضية والحاسوب** — منصة تعليمية إلكترونية تجمع كل ما يحتاجه الطالب في مكان واحد.

🌐 **رابط الموقع:** [اضغط هنا لزيارة الموقع](https://mau-misbah.github.io/MathCS-Hub/)

---

## 📖 عن المشروع
موقع تعليمي متكامل يخدم طلاب كلية العلوم الرياضية والحاسوب (تخصصات: إحصاء، رياضيات، علوم حاسوب).
يهدف الموقع إلى تسهيل وصول الطالب إلى المحاضرات، الكتب، الملخصات، والفيديوهات التعليمية، مقسمة حسب السمسترات الدراسية (10 سمسترات) والتخصص.

---

## ✨ مميزات الموقع
- 📱 **تصميم متجاوب (Responsive):** يعمل بسلاسة على الموبايل والكمبيوتر.
- 🔍 **فلاتر ذكية:** تصفية المقررات والفيديوهات والكتب حسب السمستر والتخصص.
- 📂 **تنظيم المحتوى:** تابات مخصصة داخل كل مقرر (محاضرات، كتب، ملخصات، فيديوهات).
- 🔐 **نظام تسجيل:** صفحات لتسجيل الدخول وإنشاء حساب.
- 🎛️ **لوحة تحكم:** واجهة مخصصة للإدارة للتحكم في المحتوى.

---

## 🛠️ التقنيات المستخدمة
- **HTML5** — لبناء هيكل الصفحات.
- **CSS3** — لتصميم الواجهة وتجربة المستخدم (بما فيها الـ Grid و Flexbox و Media Queries).
- **JavaScript (Vanilla)** — لبرمجة التفاعلات (قائمة الموبايل، فلاتر البحث، التابات).
- **GitHub Pages** — لاستضافة الموقع مجاناً.
